# Japanese-learning-web
我想學：日文可以完整表達組句，同時擴充單字庫。

我以前卡在：只背、說得出零碎單字和一些簡單基礎對話，但沒辦法把單字串成一段文法正確的完整句子。

我現在的程度，以及我怎麼測的：只會一些N5～N4的單字，有時候會用一些日文學習app來測驗單字程度。

5 週後我要做到：可以說出一些完整的語句，不是只用零落的單字說出我的想法。

我練習的場景、時間和每週次數：上下課通勤時間，一回大概半個小時，每週次數最少可以練習四次。

那個時候我有空的感官：視覺，觸覺。不想在通勤時帶耳機所以不想用到聽覺。

我的產品會怎麼幫我：用輕鬆好學的方式教導我完整說出正確文法的語句，並且擴充我的單字量。
